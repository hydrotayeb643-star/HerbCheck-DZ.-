HerbCheck DZ 3.0 — نموذج أولي

التشغيل:
1) فك ضغط الملف.
2) افتح index.html في متصفح حديث.
3) حساب العطار التجريبي:
   attar1@herbcheck.dz
   demo123
4) حساب الإدارة:
   admin@herbcheck.dz
   admin123

ما يتضمنه النموذج:
- واجهة عربية RTL.
- فصل تجريبي بين صلاحية العطار وصلاحية الإدارة.
- إدارة دفعات الأعشاب وسجلات ظروف التخزين.
- إضافة محلات تجريبية ولوحة إحصاءات.
- سجل للمراجع العلمية وتصدير JSON والطباعة إلى PDF.
- حفظ البيانات محليًا داخل المتصفح.

تنبيه مهم:
هذه ليست خدمة سحابية فعلية ولا نظام تسجيل دخول آمنًا. الحسابات والبيانات التجريبية موجودة داخل المتصفح، ويمكن لأي شخص لديه وصول إلى الجهاز/الملف فحصها. لا تستخدم بيانات شخصية أو تجارية حقيقية في هذا النموذج.

للتحويل إلى منصة حقيقية:
- إنشاء مشروع Supabase أو Firebase.
- إعداد مصادقة آمنة بالبريد الإلكتروني.
- إنشاء قاعدة بيانات للمستخدمين والمحلات والدفعات وسجلات التخزين والمراجع.
- فرض سياسات وصول على مستوى الصفوف (RLS) بحيث يرى كل عطار بيانات محله فقط، بينما يرى المدير المركزي البيانات وفق صلاحيات إدارية محددة.
- تخزين كلمات المرور لدى مزود المصادقة فقط، وعدم حفظها أو تضمين مفاتيح الخدمة السرية في الواجهة.
- نشر التطبيق عبر HTTPS ثم اختبار النسخ الاحتياطي واستعادة البيانات.

الحدود العلمية:
- الهاتف لا يقيس الحرارة أو الرطوبة. يجب إدخال القياسات من أجهزة خارجية.
- الرطوبة النسبية للهواء ليست محتوى الرطوبة داخل النبات.
- التنبيهات إدارية مبنية على البيانات المدخلة، وليست تصنيف جودة أو شهادة سلامة.
- لا تستخدم حدودًا رقمية موحدة لكل النباتات دون مرجع علمي موثوق خاص بالنبات والجزء النباتي وظروف التخزين.
- لا يحل التطبيق محل التحليل المخبري أو التحقق من الهوية النباتية والملوثات.

هذه نسخة عرض/اختبار وليست منتجًا جاهزًا للنشر التجاري.
